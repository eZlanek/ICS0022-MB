# Password Manager

A password manager for storing passwords in encrypted form.
The user will interact with the application through commands
in the terminal.

Development has not started yet. At the moment, only the project
plan is ready.

## Planned Commands

- init: create a new vault.
- add: add a new entry.
- list: display services and usernames without revealing passwords.
- get: reveal the password of a selected entry.
- update: edit an entry.
- delete: delete an entry.

## Planned Build and Run

The following commands will be used after the source code and
build configuration are implemented. Run them from the project folder.

Prepare the build in the `build` directory:

```bash
cmake -S . -B build
```

Build the application:

```bash
cmake --build build
```

Run the application and show the available commands:

```bash
./build/password_manager --help
```

These commands cannot build or run the project yet because
only the design is ready.
